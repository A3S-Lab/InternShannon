## 测试分层定义

1. 单元测试：直接验证纯函数、策略、状态转换、脱敏及错误映射。
2. 集成测试：验证多个模块之间的契约，包括 Sidecar 拦截器/Runner、组件状态与生产构建契约。
3. 探针测试：对正在运行的生产 Sidecar、生产 Web 产物或浏览器 DOM 执行编号专属断言。
4. WebSocket 真实链路：使用生产 Sidecar、真实 Socket.IO WebSocket transport、真实会话仓储和房间广播，不替换 Gateway 或 Socket 服务端。

对于不依赖 WebSocket 的纯 UI 项，功能本身由浏览器和编号专属探针直接验证；三组 WebSocket 用于确认真实会话状态驱动、重连和安全隔离不会让该页面功能回归。它们不被表述为 UI 功能本身的直接证明。

## 三个 WebSocket 真实场景

每个 SXA 编号都创建独立测试会话并执行以下三组场景，结束后删除会话。

| 场景 | 真实输入 | 必须观察到的事件链 |
|---|---|---|
| A：可信订阅与快照 | `Origin: tauri://localhost` 建立 WebSocket，发送 `subscribe` | `connect → subscribed → session_init → cli_connected` |
| B：状态更新与取消 | 发送 `set_permissionMode(plan)`、`set_autoExecute(true)`、`cancel` | 房间广播返回两个 `session_update`，随后返回 `cancelled` |
| C：恶意来源与错误恢复 | 攻击 Origin 握手；可信连接先订阅不存在会话，再订阅有效会话 | 攻击连接 `connect_error`；无效会话返回访问错误；同一可信客户端随后成功 `subscribed` |
