# 第一部分 · 认识书小安

## 1. 书小安是什么

书小安是一款**装在你自己电脑上的知识工作台**。

它把四件通常要分开做的事，收进同一个窗口：

| | |
|---|---|
| **问** | 基于你自己的资料回答问题，而不是泛泛而谈 |
| **找** | 在你导入的文档里检索，告诉你答案来自哪个文件 |
| **改** | Word、Excel、PPT 直接在应用里打开、修改、存回原文件 |
| **做** | 让智能体替你读日志、写文档、跑命令——但动手之前先问你 |

和常见的 AI 助手最大的不同：**你的文件不需要上传到别人的服务器**。资料放在你电脑的一个文件夹里，索引也建在本地，改完的文件还在原来的位置。

> 需要说明一点：书小安本身不含大模型。它需要你配置一个模型服务（可以是 OpenAI、Anthropic、智谱，也可以是你公司内网自建的兼容接口）。你的问题和相关文本会发给这个模型服务，但**文件本身不会被上传**。

---

## 2. 它替你省掉哪些麻烦

### 麻烦一：同一批资料反复上传

云盘存一份、AI 助手里传一份、本地下载一份。换个对话，再传一遍。

**书小安**：资料放进知识库一次，之后一直可用。下次再问，不用再传。

### 麻烦二：答案和原文对不上

助手给了结论，你想核实，它只能说「大概在某个文档里」。你还得自己打开文件搜关键词。

**书小安**：检索结果直接告诉你是哪个文件，点一下就在同一个窗口里打开它。

### 麻烦三：改个表格要绕一大圈

想改一个 Excel，得先下载，用 Office 打开，改完保存，再上传覆盖。中间走错一步，版本就分叉了。

**书小安**：在应用里直接打开 xlsx，改完点保存，写回原文件。不下载，不上传。

### 麻烦四：自动执行像个黑盒

有些智能体动手很快，但你只能事后检查。等发现问题，改动已经发生了。

**书小安**：读文件、搜索这类只读操作自动放行，不打断你；但要写文件、跑命令时会先弹窗问你，你点了同意才执行。

## 3. 一眼看懂：书小安是怎么工作的

```
        你的电脑
┌───────────────────────────────────────────────────┐
│                                                    │
│   ┌──────────────────────────────────────┐        │
│   │  书小安窗口                            │        │
│   │  对话 · 知识库 · 文件编辑器 · 设置      │        │
│   └───────────────┬──────────────────────┘        │
│                   │                                │
│   ┌───────────────▼──────────────────────┐        │
│   │  本地服务（随应用自动启动）             │        │
│   │  · 管理会话和消息                      │        │
│   │  · 建立和检索知识库索引                 │        │
│   │  · 读写你的文件                        │        │
│   └───────────────┬──────────────────────┘        │
│                   │                                │
│   ┌───────────────▼──────────────────────┐        │
│   │  你的工作区文件夹                       │        │
│   │  资料、索引、会话记录，全部在这里        │        │
│   └──────────────────────────────────────┘        │
│                                                    │
└─────────────────────┬─────────────────────────────┘
                      │  只有「问题 + 相关文本片段」
                      │  会发出去
                      ▼
              你配置的模型服务
      （OpenAI / Anthropic / 智谱 / 公司内网）
```

**三句话解释：**

1. 你安装的是一个完整的应用。它自带一个本地服务，开机即用，**不需要装数据库、配服务器或部署到云上**。
2. 你的文件、知识库索引、会话记录，全部存在你电脑上的一个文件夹里。想搬走或备份，拷走这个文件夹就行。
3. 只有在需要模型回答时，书小安才会把你的问题和检索到的相关文本发给模型服务。**文件本身不会离开你的电脑。**

# 第二部分 · 开始使用

## 4. 安装

### 4.1 下载安装包

| 系统 | 安装包 |
|---|---|
| macOS | `.dmg` |
| Windows | `InternShannon-*-setup.exe` |
| Linux | `.deb`（也提供 AppImage） |

### 4.2 安装步骤

**macOS**
打开 `.dmg`，把 `InternShannon.app` 拖到「应用程序」文件夹。

**Windows**
双击 `setup.exe`。安装为**当前用户**，默认位置 `%LocalAppData%\InternShannon`，不需要管理员权限。

> 安装过程中如果系统缺少 WebView2 运行时，安装程序会自动联网下载。首次安装请保持网络畅通。
>
> 目前 Windows 版仅支持 **64 位 Intel/AMD 处理器**，暂不支持 ARM64 设备。

**Linux**

```bash
sudo dpkg -i internshannon_0.2.1_amd64.deb
```

---

## 5. 第一次启动

### 5.1 启动等待

第一次打开书小安时，会看到一个启动画面，提示「首次启动可能会持续几十秒」。

这是正常的。应用在后台启动本地服务并初始化目录，请耐心等待，不要反复重启。

### 5.2 完成首次默认配置

启动完成后会弹出一个**必须填完的配置窗口**，标题是「完成首次默认配置」。这个窗口不能跳过，也不能点外面关掉——配置没完成前，无法新建会话。

需要填三样东西：

#### 第一步：个人资料

设置头像和昵称。昵称默认是「本地用户」，可以改成你自己的名字。

#### 第二步：默认工作区

这是书小安存放你所有资料和会话的**根目录**。

默认路径是：

| 系统 | 默认工作区 |
|---|---|
| macOS / Linux | `~/.internshannon/workspace` |
| Windows | `C:\Users\你的用户名\.internshannon\workspace` |

点「浏览」可以改成你喜欢的位置，比如 `D:\书小安工作区`。

> **建议**：如果你的资料比较多，选一个磁盘空间充足的位置。这个目录后面还能改，但已经建好的会话不会自动搬过去。

#### 第三步：AI 服务

**这一步最关键。书小安不自带大模型，你必须配置一个模型服务，否则它无法回答任何问题。**

需要填：

| 字段 | 说明 |
|---|---|
| 服务商 | Anthropic / OpenAI / 智谱 GLM / OpenAI 兼容接口 |
| API Key | 你从服务商那里获取的密钥 |
| Base URL | 选了预设服务商会自动填好；选「OpenAI 兼容接口」时需要自己填 |
| 模型 | 添加至少一个模型，并设为默认 |

预设服务商的默认地址：

| 服务商 | 默认 Base URL |
|---|---|
| Anthropic | `https://api.anthropic.com` |
| OpenAI | `https://api.openai.com/v1` |
| 智谱 GLM | `https://open.bigmodel.cn/api/paas/v4` |

> **公司内网自建模型**：选「OpenAI 兼容接口」，把 Base URL 填成你们内部的服务地址即可。

填完点保存，配置窗口关闭，就可以开始用了。

> **以后想重新走一遍这个流程**：设置 → 关于 → 「重新打开首次配置」。

# 第三部分 · 完整教程

## 教程一：第一次对话

### 步骤 1 · 新建会话

点左侧「**对话**」。

如果还没有任何会话，中间会显示「开始一段书小安会话」，点「**新建会话**」。

如果已有会话，在左侧会话列表顶部点「**+**」（新会话）。

创建成功会有提示「会话创建成功」。

### 步骤 2 · 认识输入框

底部输入框的提示文字是：

> 输入消息，/ 触发指令，@ 提及工作区文件…

三种输入方式：

| 输入 | 作用 |
|---|---|
| 直接打字 | 普通提问 |
| 输入 `/` | 触发技能（斜杠指令） |
| 输入 `@` | 提及工作区里的某个文件，让书小安读它 |

**发送**：点右侧发送按钮，或按 `Ctrl + Enter`（Mac 上是 `⌘ + Enter`）。

### 步骤 3 · 选模型和执行模式

输入框下方有一排状态控件。

**模型选择器**（CPU 图标）：切换本次会话用哪个模型。如果显示「未配置模型」，说明 AI 服务还没配好，去设置里补上。

**执行模式**：三选一，决定书小安动手的自由度。

| 模式 | 行为 | 什么时候用 |
|---|---|---|
| **默认模式** | 正常执行。读取类操作自动放行，写文件和跑命令会弹窗问你 | 日常使用，**推荐** |
| **规划模式** | 只分析和规划，只允许读取、浏览、搜索，不改任何东西 | 想先听方案，不想它动手 |
| **自动执行** | 直接执行可用工具，不逐次确认 | 你完全信任的工作区，追求速度 |

> 三种模式随时可切，不用重建会话。

### 步骤 4 · 上传文件到会话

两种方式：

- 点输入框旁的**上传图标**（提示「上传文件到工作区」），选择文件
- 直接把文件**拖到输入框**上，会出现「松开上传到当前会话工作区」

> 目前只支持拖入**文件**，拖文件夹会被跳过并提示「已跳过文件夹，当前仅支持拖入文件」。
>
> 截图可以直接 `Ctrl + V` 粘贴进来。

### 步骤 5 · 中断和「悄悄话」

书小安执行任务时，输入框左侧会出现一个**红色的中断按钮**，点它可以停止当前任务。

任务运行期间，输入框会自动切换到**悄悄话模式**，提示语变成「输入悄悄话…（不中断主任务）」，发送按钮变成琥珀色的「发送悄悄话」。

用途：任务跑到一半你想补充一句说明，又不想打断它重来。悄悄话会在不中断主任务的前提下传达给书小安。

### 步骤 6 · 会话管理

会话列表顶部有搜索框（「搜索会话」）。

聊天区顶部工具栏可以：

- **搜索消息** —— 在当前会话里查找
- **记录操作** —— 「复制会话记录」或「导出原始数据」
- **打开工作区** —— 打开本次会话的文件夹

## 教程二：建立你的知识库

这是书小安最核心的能力：把你的资料变成可检索的本地知识库。

### 步骤 1 · 进入知识库

点左侧「**知识库**」。

书小安会自动为你准备好一个知识库，**不需要手动创建**。页面顶部会显示当前的页面数、来源数和最后更新时间。

### 步骤 2 · 导入资料

点右上角「**导入资料**」，在弹出的文件选择框里选文件（可以多选）。

支持的资料类型：

| 类型 | 说明 |
|---|---|
| 纯文本 | txt、md、csv、json、yaml、xml、html、log 等 |
| PDF | 直接抽取文字 |
| Word | docx |
| Excel | xlsx |
| 图片 | png、jpg、gif、webp、bmp、tiff、heic（需要先配置 OCR，见下文说明） |

单个文件上限 **50 MB**。

> **只能选文件，不能选文件夹。** 知识库页面也不支持拖拽导入，请用「导入资料」按钮。

导入后会看到提示「资料已加入知识库」，告诉你有几个文件正在后台处理。

### 步骤 3 · 等待索引完成

导入后书小安会在后台做四件事：抽取文字 → 切分片段 → 建立向量索引 → 发布。

右上角的「**刷新索引**」按钮在处理期间会变成「**索引中 XX%**」，实时显示进度。

想看详细进度，点右侧活动栏的「**任务与审计**」面板，那里有每个任务的进度条，还可以取消或重试。

### 步骤 4 · 检索

点右侧活动栏的「**库概览**」面板，上方有搜索框「**查找页面或标签**」。

输入关键词，结果会实时出现，每条显示：

- **标题**
- **文件路径**
- **内容摘要**

**点击任意一条结果，对应文件会在中间区域打开。**

### 步骤 5 · 认识其他面板

知识库页面右侧活动栏有七个面板：

| 面板 | 你能在这里做什么 |
|---|---|
| **资源管理器** | 浏览知识库文件树，新建文件/文件夹，编辑内容 |
| **库概览** | 看统计（页面数、来源数、断链数、已索引、孤立页），搜索，管理来源 |
| **关系图** | 可视化查看页面之间的链接关系，可按类型和标签筛选 |
| **反向链接** | 查看有哪些页面链接到当前打开的这一页 |
| **策展建议** | 审阅系统给出的建链、摘要、合并建议，可接受或拒绝 |
| **任务与审计** | 查看导入和索引任务进度，查看操作审计记录 |
| **检索配置** | 调整检索策略和向量服务 |

### 步骤 6 · 处理没索引成功的资料

在「库概览 → 来源」里，每个来源都会显示状态。如果某个文件没索引成功：

| 状态 | 原因 | 怎么办 |
|---|---|---|
| 等待 OCR | 是图片或扫描件，但 OCR 后端没启用 | 点「**配置后重试**」 |
| 不支持 | 文件类型不支持 | 换个格式重新导入 |
| 出错 | 超过 50 MB，或抽取失败 | 点「**重新抽取**」重试 |

> **关于 OCR**：书小安支持从图片和扫描版 PDF 里提取文字，但需要接入一个 OCR 服务。**当前版本的设置页面还没有 OCR 配置区**，需要通过配置接口设置。如果你有这个需求，请联系我们协助配置。

### 步骤 7 · 调整检索策略（可选）

点「**检索配置**」面板，有三个预设：

| 预设 | 适合 |
|---|---|
| **平衡（推荐）** | 大多数情况 |
| **精确匹配** | 你记得确切的词，想要精准命中 |
| **高召回** | 宁可多返回一些，不想漏 |

高级选项里可以配置向量服务和向量模型。默认使用**内置的离线向量算法**，不需要联网，也不需要额外配置——如果你希望检索的语义理解更强，可以在这里接入 OpenAI 兼容的嵌入服务。

改完点「保存」，也可以「恢复默认」。

### 步骤 8 · 打包带走你的知识库

顶部有两个图标按钮：

- **导出 OKF 知识包** —— 把整个知识库打包成一个 zip
- **导入 OKF 知识包** —— 把别人给你的知识包导进来

用于在多台电脑之间迁移，或者团队内部分享一套整理好的知识库。

## 教程三：在书小安里改 Office 文件

### 支持的格式

| 格式 | 打开后的编辑器 |
|---|---|
| `.docx` | 文档编辑器 |
| `.xlsx` / `.xls` / `.ods` | 表格编辑器 |
| `.pptx` | 演示文稿编辑器 |

> 老版二进制格式 `.doc`、`.ppt` 和 `.odt`、`.odp` 暂不支持。界面会明确提示，不会静默出错。

### 步骤 1 · 打开文件

在知识库的「资源管理器」面板里，点击任意 Office 文件，它会在中间区域**以标签页的形式打开**，就像 VS Code 一样。可以同时开多个标签。

### 步骤 2 · 编辑

直接在编辑器里改。修改单元格、编辑文字、调整幻灯片文本都可以。

编辑器右上角会显示当前状态：

| 状态 | 含义 |
|---|---|
| **已保存** | 一切正常 |
| **未保存** | 有改动还没存 |
| **保存中** | 正在写入 |
| **只读** | 当前不可编辑 |
| **错误** | 保存出了问题 |

### 步骤 3 · 保存

三种方式：

- 点编辑器顶部的「**保存**」按钮
- 按 `Ctrl + S`（Mac 上是 `⌘ + S`）
- 点工具栏的保存图标

保存成功会提示「文档已保存」/「表格已保存」/「演示文稿已保存」。

**改动直接写回原文件。** 没有下载，没有上传，没有另存为一个新副本。文件里你没动过的部分——图表、图片、格式、主题——原样保留。

### 步骤 4 · 遇到保存失败怎么办

书小安在两种情况下会**主动拒绝保存**：

1. 文件被标记为只读
2. 你的改动涉及复杂结构变更（比如给含图表的工作簿改工作表名或改样式结构）

第二种是刻意设计的保护：与其存出一个可能损坏的文件，不如明确告诉你这条路走不通。这时可以点「**重试保存**」或「**重新加载**」，或者换一种改法。

### 步骤 5 · 文件在外面被改了

如果你在书小安里有未保存的改动，同时这个文件在磁盘上被其他程序改了，书小安会弹窗提示：

> 当前文件在磁盘上发生变化，同时编辑器里还有未保存内容

你可以选择比对差异、重新加载、或用你的版本覆盖。不会静默覆盖任何一方。

## 教程四：让书小安动手做事

书小安不只是回答问题，它可以读文件、写文件、执行命令。**关键在于它动手之前会先问你。**

### 什么时候会弹窗

| 操作类型 | 行为 |
|---|---|
| 读文件、列目录、搜索、网络搜索 | **自动放行**，不打断你 |
| 写文件、改文件、执行命令 | **弹窗确认** |

这个规则在「**默认模式**」下生效。切到「自动执行」就不再逐次确认，切到「规划模式」则完全不允许动手。

### 确认窗口长什么样

弹窗标题是「**工具执行确认**」，会显示：

- **工具名称** —— 它想干什么
- **工具参数** —— 具体参数（比如要写哪个文件、写什么内容）
- **授权范围** —— 三选一

三档授权范围：

| 选项 | 含义 |
|---|---|
| **仅此一次**（默认） | 只批准这一次，下次同样的操作还会再问 |
| **本次任务** | 当前任务完成前，同类操作自动放行 |
| **整个会话** | 这个会话期间都自动放行 |

底部两个按钮：「**拒绝**」和「**确认授权**」。

> **小技巧**：选好授权范围后直接按 `Enter` 就是确认。
>
> **注意**：点右上角 X 或点窗口外面关闭，等同于**拒绝**。

### 超时会怎样

如果你 60 秒内没有做选择，这次操作会被**自动拒绝**，不会偷偷执行。任务会带着「被拒绝」的结果继续，你可以再让它试一次。

### 一个实际例子

> **你**：帮我看看 logs 目录下昨天的错误日志，总结一下问题，写进 `复盘.md`
>
> **书小安**：（读取 logs 目录 —— 自动放行，不打断）
> （读取几个日志文件 —— 自动放行）
> 我发现了三类错误…（分析内容）
> 现在我要创建 `复盘.md`
>
> **弹窗**：工具执行确认 · write_file · 路径 `复盘.md` · [仅此一次] [本次任务] [整个会话] · 拒绝 / 确认授权
>
> **你**：点「确认授权」
>
> **书小安**：已写入 `复盘.md`

整个过程里，读日志没有打断你，只有真正要落盘的那一步停下来征求同意。

## 教程五：用技能定制书小安

**技能**是一段写给书小安的指令，告诉它在某类任务上应该怎么做。写一次，之后反复用。

### 步骤 1 · 进入技能页

点左侧「**技能**」，页面标题是「书小安配置」，分三个区：

| 区域 | 用途 |
|---|---|
| **参数配置** | 新建会话时的默认设置 |
| **我的技能** | 只有你自己用的技能文件 |
| **共享技能** | 团队共用的技能文件 |

### 步骤 2 · 设置默认参数

在「参数配置」里可以设：

- **默认模型** —— 新会话默认用哪个
- **默认权限模式** —— 新会话默认是「默认模式」「规划模式」还是「自动执行」
- **默认启用技能** —— 内置技能开关，以及自定义技能名（每行一个）
- **规划选项**

改完点「**保存配置**」。

### 步骤 3 · 写一个技能

在「我的技能」区，用文件树上方的「**新建文件**」创建一个技能文件。书小安会生成一个带模板的 Markdown：

```markdown
---
name: 周报生成
description: 按公司格式整理本周工作周报
kind: instruction
---

请按以下格式整理周报：

## 本周完成
（按项目分组，每项一句话说清结果）

## 下周计划
（列出 3-5 项，标注优先级）

## 风险与阻塞
（如果没有就写「无」）

要求：
- 用陈述句，不要用「进行了」「开展了」这类虚词
- 每条不超过 30 字
```

写完按 `Ctrl + S` 保存。页面顶部会显示「文件已保存」。

### 步骤 4 · 使用技能

回到对话页，在输入框里输入 `/`，会列出可用技能，选中即可触发。

### 技能文件存在哪

界面上会显示完整路径：

| 类型 | 路径 |
|---|---|
| 个人技能 | `{工作区根目录}/users/{你的用户ID}/skills` |
| 共享技能 | `{工作区根目录}/users/{你的用户ID}/shared/skills` |

这是普通文件夹，你可以直接用系统的文件管理器打开、备份或分享给同事。

## 教程六：接入外部工具（MCP）

MCP 是一个开放标准，让 AI 应用能接入各种外部工具。接入后，书小安就能调用这些工具。

### 步骤 1 · 打开 MCP 设置

设置 → **MCP 服务**。

### 步骤 2 · 添加服务

有两种方式：

**方式一：从官方库导入**
在预设下拉框里选一个现成的服务，字段会自动填好。

**方式二：手动填写**

| 字段 | 说明 |
|---|---|
| **服务名** | 自己起个名字 |
| **传输方式** | `stdio`（本地程序）或 `http`（网络服务） |
| **Command** | stdio 方式：要执行的命令 |
| **Args（空格分隔）** | stdio 方式：命令参数 |
| **URL** | http 方式：服务地址 |
| **Headers（KEY=VALUE，每行一个）** | 需要的请求头，比如认证 |
| **Env（KEY=VALUE，每行一个）** | 环境变量 |
| **超时（秒）** | 默认 60 |

填完点「**添加服务**」。

### 步骤 3 · 管理服务

服务列表可以按「全部 / 已启用 / 已连接」筛选。每一行可以启用、禁用、编辑、删除。

### 提醒

MCP 服务调用外部工具时，同样受**确认机制**保护。如果某个 MCP 工具要改你的文件或执行命令，一样会弹窗问你。

## 13. 设置详解

设置页面共八个分区：

| 分区 | 主要内容 |
|---|---|
| **工作区** | 工作区根目录（可浏览选择），会话与目录结构说明 |

| **MCP 服务** | 外部工具服务的增删改查 |
| **搜索引擎** | 默认搜索引擎、无头浏览器路径、代理、语言、安全搜索级别 |
| **编辑器** | 字体、快捷键自定义 |
| **外观** | 主题：跟随系统 / 浅色 / 深色 |
| **更新** | 版本检查 |
| **关于** | 产品信息、项目链接、「重新打开首次配置」 |

### 换工作区根目录

设置 → 工作区 → 修改「工作区根目录」→ 点「保存」。

新目录会用于**之后**新建的会话和技能目录。已经存在的会话不会自动搬迁。

### AI 服务的自动保存

AI 服务分区的改动会在你停止编辑约 0.8 秒后**自动保存**，不需要手动点保存。

> 想确认模型配置是否有效，可以在模型列表处刷新一次模型列表——能拉到模型说明连接正常。

## 15. 常见问题

### 启动相关

**Q：第一次打开要等很久，是卡住了吗？**
不是。首次启动需要初始化本地服务和目录，可能持续几十秒。界面上会有提示。请等待，不要反复重启。

**Q：一直卡在启动画面进不去。**
本地服务可能没起来。先完全退出应用再重开一次。如果仍然不行，检查是否有其他程序占用了 `29653` 端口。

**Q：配置窗口关不掉。**
「完成首次默认配置」是必填的，三项（个人资料、工作区、AI 服务）都填完才能关闭。其中 AI 服务必须至少配置一个服务商和一个默认模型。

### 使用相关

**Q：提问后报错说没有配置模型。**
去「设置 → AI 服务」，确认：至少有一个服务商、服务商下至少有一个模型、已经设置了默认模型、API Key 填对了。

**Q：模型选择器显示「未配置模型」。**
同上，AI 服务没配好。

**Q：导入的 PDF 搜不到内容。**
可能是扫描版 PDF（图片形式，没有文字层）。在「库概览 → 来源」里看这个文件的状态，如果是「等待 OCR」，需要先配置 OCR 服务。

**Q：文件夹拖不进去。**
目前只支持拖入单个文件。知识库请用「导入资料」按钮，会话请用上传按钮。

**Q：书小安执行到一半停住不动了。**
看看是不是弹出了「工具执行确认」窗口在等你。另外，如果超过 60 秒没响应，这次操作会自动被拒绝。

**Q：不想每次都弹窗确认。**
两个办法：在确认窗口里选「本次任务」或「整个会话」授权范围；或者把执行模式切到「自动执行」。

**Q：想让它只出方案不动手。**
把执行模式切到「规划模式」。

### 文件相关

**Q：`.doc` 文件打不开。**
不支持老版二进制格式。请先用 Office 另存为 `.docx`。

**Q：Excel 保存失败。**
如果工作簿里有图表，改工作表名或改样式结构会被拒绝，这是为了防止文件损坏。可以试试只改单元格内容，或者用外部 Office 完成这类结构性修改。

**Q：我的文件会被上传到云上吗？**
不会。文件的读写都在你电脑本地完成。只有你的问题和检索到的相关文本片段，会发给你自己配置的模型服务。

### 数据相关

**Q：怎么备份？**
拷走你的数据目录（默认 `~/.internshannon`）就行，里面包含配置、会话记录和工作区。

**Q：怎么换台电脑？**
把数据目录拷到新电脑的同样位置。知识库也可以单独用「导出 OKF 知识包」打包迁移。

**Q：API Key 存在哪里？安全吗？**
存在你电脑上的 `~/.internshannon/config.json`。界面和日志里会打码显示，但**磁盘上是明文**。请像对待其他本地配置文件一样保护好这台电脑。

## 16. 你的数据存在哪里

### 数据根目录

| 系统 | 路径 |
|---|---|
| macOS / Linux | `~/.internshannon` |
| Windows | `C:\Users\你的用户名\.internshannon` |

里面包含：

| 文件 | 内容 |
|---|---|
| `config.json` | 应用设置（含 API Key） |
| `config.hcl` | 界面偏好 |
| `sessions.json` | 会话列表 |
| `messages.json` | 聊天记录 |
| `workspace/` | 工作区 |

### 工作区结构

```text
workspace/
├── agents/     智能体工作目录
├── sessions/   每个会话的文件
├── logs/       日志
└── users/      你的个人技能、共享技能、会话
```

### 知识库结构

```text
知识库/
├── raw/sources/      你导入的原始文件
├── wiki/             知识页面（Markdown）
└── .internshannon/   索引数据（请勿手工修改）
```

`raw/sources` 里就是你导入的原始文件本身，随时可以直接打开或拷走。
