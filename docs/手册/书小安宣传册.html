四件事，一个窗口

以前要在四个软件之间来回切换才能完成的链条，现在从头到尾不用离开书小安。

问
基于你自己的资料回答
把文档扔进知识库，之后所有提问都建立在你的真实材料上，而不是模型的泛泛记忆。导入一次，长期可用。
找
答案能追回原文
每个检索结果都带着它来自哪个文件。点一下，原文就在同一个窗口里打开，不用切出去翻。
改
Word、Excel、PPT 就地改完存回去
在书小安里直接打开、修改、保存。写回原文件，图表、图片、格式一样不动。全程不下载、不上传。
做
会动手，但先问你
读文件、搜索这类操作自动放行不打断你；要写文件、跑命令时先弹窗征求同意。速度不打折，方向盘在你手上。

客户续费运营
9 步压到 3 步，三个应用并成一个
以前
开云盘找资料 → 上传到助手 → 提问 → 只拿到文档名，手工核对 → 下载台账 → Office 打开 → 改 → 存 → 传回云盘
现在
资料入库 → 同窗口提问 → 点结果看原文 → 同窗口改台账存回原文件
文献综述
追加资料不用重来，已有的直接复用
以前
逐篇上传 5 篇 → 提问 → 没有出处，手工在 PDF 里搜 → 加第 6 篇 → 全部重传重建 → 再提问
现在
6 篇一次入库 → 提问 → 点结果看原文 → 加新的只处理新的 → 再提问

少 2 步，产物不用导出合并
以前
配平台 → 传日志 → 启动智能体 → 自动执行完事后审查 → 导出产物 → 合并回本地
现在
打开会话 → 提问，它直接读本地日志 → 要写文件时问你一句 → 产物直接落在本地
